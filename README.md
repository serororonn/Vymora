# Vymora

Vymoraは、音源からDAW編集用のMIDI素材を作るAudio2MIDIプロジェクトです。

現在の実装は`../python`にあります。音源をDemucsで分離し、ボーカル、ベース、ギター、ピアノ、その他、キック、スネア、ハイハットの8トラックを1つのMIDIへまとめます。

## 開発状況

- ローカルWeb UI: 実装済み
- 進捗ゲージ: 実装済み
- 楽器別ステム分離: 実装済み
- 8トラックMIDI出力: 実装済み
- 正解MIDIとの精度比較: 実装済み
- 高精度ニューラルモデルの安定した配布: 未実装
- Windows exe配布: 未実装

詳細なセットアップ、変換方式、評価方法は、親リポジトリのREADMEを参照してください。
